# Graft model prompts

One image prompt per graft card (97), for the image generator. Each describes the part shown in that card's artwork as a single object, ready to turn into 3D.

## How to use

1. Paste a prompt into the image generator (FLUX.1 schnell, for example) and pick the cleanest result.
2. Cut it out (remove the background) if the white isn't clean.
3. Make the 3D model in TRELLIS.2 with the same settings you used for the Specimen.
4. Save the model as `<card id>.glb`, using the file name under each heading (e.g. `pred_bone_spur.glb`), in `src/assets/models/grafts/`.
   The game then shows it in place of that card's placeholder part. No code needed.
5. The part's base (where it touches the body) should be at the bottom, pointing up. If a model comes out sideways, send it to me and I'll turn it.

Where each slot sits: **Head** on top of the helmet, **Nerve** on the front of the neck (a collar), **Organ** in the centre of the chest, **Limb** on the outside of a forearm.
